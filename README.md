# 团课刷题

共青团知识题库刷题网页（143 题），支持错题重做、收藏、答题进度本地保存。

## 功能

- **全部练习**：按题库顺序 143 题
- **随机 20 题**：随机抽题快速自测
- **错题重做**：答错的题自动进入错题本，重做答对后自动移出
- **我的收藏**：随时标记想复习的题
- **按题型练习**：单选 100 / 多选 6 / 填空 24 / 简答 3 / 背诵卡 10
- **进度记忆**：答题记录、错题、收藏、上次练习位置都保存在浏览器本地（localStorage），关掉网页下次打开自动继续
- **设置与备份**：可导出 / 导入进度 JSON，换设备不丢

## 本地使用

直接用浏览器打开 `index.html` 即可，无需服务器、无需联网。

## 说明

- 进度只保存在**当前浏览器**，换浏览器或清除数据后会丢失，建议用「设置与备份」里的导出功能定期备份。
- 题目内容来自《团课题库》Word 文档，填空题按 `/` 或「或」分隔的答案任一即可判对。
